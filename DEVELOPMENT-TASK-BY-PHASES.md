# DEVELOPMENT-TASK-BY-PHASES.md — Mental Wellness & Mindfulness Self-Reflection Advisor

This is the phased build plan for turning this scaffold into a working Claude Skill, following the skill-creator methodology (draft → test → evaluate → iterate → package).

## Phase 1 - Foundation
**Goal:** Non-diagnostic safety framework

**Tasks:**
- [ ] Draft SKILL.md with explicit 'never diagnose' rule and crisis-resource triggers
- [ ] Build reflective-journaling prompt library (CBT/ACT informed)

## Phase 2 - Mindfulness Module
**Goal:** MBSR-informed practice

**Tasks:**
- [ ] Build guided mindfulness/breathing exercise scripts
- [ ] Add stress-reduction technique reference

## Phase 3 - Values & Coping
**Goal:** ACT-informed exercises

**Tasks:**
- [ ] Build values-clarification exercise templates
- [ ] Add cognitive-defusion technique explainer

## Phase 4 - Wellbeing Education
**Goal:** Plain-language psychoeducation

**Tasks:**
- [ ] Build PERMA-model wellbeing explainer
- [ ] Add stigma-free, non-diagnostic language style guide

## Phase 5 - Safety Testing & Polish
**Goal:** Validate safety behavior

**Tasks:**
- [ ] Test against scenarios that should trigger professional-referral or crisis-resource responses
- [ ] Confirm no diagnostic language appears in any output
- [ ] Package with disclaimers

## Final Step — Packaging

- [ ] Write the actual `SKILL.md` (name + description + body) based on the specification in `PROJECT-detail.md`
- [ ] Build any `references/`, `scripts/`, or `assets/` the skill needs
- [ ] Run the skill-creator evaluation loop (test prompts, review, iterate)
- [ ] Package the finished skill for distribution
