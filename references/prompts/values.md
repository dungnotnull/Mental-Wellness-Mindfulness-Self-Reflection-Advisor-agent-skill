# Values Clarification Prompts — ACT-Informed Values Work

**Purpose:** Provide structured values clarification exercises grounded in ACT principles for identifying what matters most and living with intention.

> **Use these prompts for:** Values exploration, life direction clarification, goal setting aligned with values, and meaningful action planning.

## What Are Values?

**Definition:** Values are chosen life directions — what you want your life to be about, stand for, and represent.

**Key Distinctions:**
- **Values ≠ Goals:** Goals are destinations; values are the compass direction
- **Values ≠ Feelings:** Values persist regardless of current emotions
- **Values ≠ Shoulds:** Values are freely chosen, not imposed
- **Values ≠ Outcomes:** Values are about how you live, not what you achieve

**Educational Language:**
- "Values are like a compass — they guide direction but not destination"
- "Values are who you want to be and how you want to act"
- "Values are freely chosen life directions"

## Values Clarification Exercises

### 1. Values Bull's Eye

**For each domain, complete this exercise:**

```
DOMAIN: ___________________

1. WHAT MATTERS
   Deep down, what matters to you in this area?
   List 3-5 core values:
   
   a. _____________
   b. _____________
   c. _____________
   d. _____________
   e. _____________

2. VISION STATEMENT
   If you were fully living your values in this domain,
   what would that look like?
   Free-write your ideal vision:
   
   _______________________________________________
   _______________________________________________
   _______________________________________________

3. CURRENT ALIGNMENT
   Rate how aligned you are with these values (1-10):
   
   Current: ____ / 10
   
   Where are you on the bull's eye?
   
   Center (10)                    Edge (1)
        |                              |
        |                              |
     YOU ✘ (mark your current spot)
        |                              |
        |                              |

4. DESIRED ALIGNMENT
   Where would you like to be?
   
   Desired: ____ / 10
   Mark with ✘ above where you'd like to be

5. THE GAP
   What's the difference between current and desired?
   
   _______________________________________________
   _______________________________________________

6. BARRIERS
   What gets in the way?
   - Thoughts? ("I'm not good enough")
   - Feelings? (Anxiety, sadness)
   - Situations? (Time, resources)
   
   _______________________________________________
   _______________________________________________

7. DEFUSION
   Can you make space for these barriers
   while still moving toward your values?
   What if you noticed them without struggling?
   
   _______________________________________________

8. COMMITTED ACTION
   What's one specific, achievable action this week?
   Something you can actually do, even imperfectly:
   
   _______________________________________________
   
   When? ___________
   
   How will you know it's done?
   _______________________________________________

Repeat this exercise for each domain that matters to you.
```

## Common Barriers to Values-Based Living

### Barrier: "I Don't Know My Values"

```
If you're unclear on values:

1. Notice what angers you in the world
   What injustices upset you?
   Your values are the opposite of what angers you

2. Notice who you admire
   What qualities do they embody?
   Those likely reflect your values

3. Notice your "best self" moments
   When have you felt most proud of yourself?
   What values were you living?

4. Start with elimination
   What definitely DOESN'T matter to you?
   What remains might matter

5. Choose experimentally
   Pick a possible value and live it for a week
   Notice how it feels
   Adjust based on experience
```

### Barrier: "I Have Too Many Values"

```
If you're overwhelmed by values:

1. Prioritize for NOW
   Which values matter most in THIS season of life?

2. Choose 3-5 core values
   Make these your focus for 3 months

3. Don't abandon others
   Just make them secondary for this period

4. Re-evaluate periodically
   Values priorities shift over time
   Check in quarterly
```

### Barrier: "I Can't Live My Values Because..."

```
Common "I can't because" barriers:

"I can't because [EXTERNAL SITUATION]"
→ What's one small action you CAN take within this situation?

"I can't because [HOW I FEEL]"
→ Can you feel [emotion] and act anyway?

"I can't because [WHAT OTHERS THINK]"
→ What would matter to you if no one was watching?

"I can't because [FEAR OF FAILURE]"
→ What if failure was part of living your values?

"I can't because [NOT ENOUGH TIME/MONEY]"
→ What values-aligned action IS possible with what you have?
```

## Safety Notes

**Values work can bring up:**
- Sadness about misaligned life areas
- Anxiety about change
- Grief about time spent off-values
- Confusion about priorities

**If overwhelmed:**
- Take a break from values work
- Return to basics: what matters THIS week?
- Remember: values are directions, not demands
- Be kind to yourself about the past

**Consider professional support if:**
- Values confusion persists long-term
- Misalignment is causing severe distress
- You feel stuck and unable to move

These exercises are educational tools.
For deeper values work, consider ACT-based therapy with a licensed professional.
